# Directory Structure

| Domain | What it makes visible |
|---|---|
| 00 Constitutional source | primary source identity, hashes, amendment lineage |
| 01 Office and role registry | office, officeholder, term, oath, succession, role limits |
| 02 Legislative origin | bill, sponsor, committee, text changes, vote, enactment lineage |
| 03 Statute to execution | statutory authority mapped to an actual public action |
| 04 Delegation and revocation | principal, delegate, scope, duration, revocation, subdelegation |
| 05 Jurisdiction and federalism | federal/state/local boundary, conflict, recognition, preemption claim |
| 06 Appointments and confirmations | nomination, confirmation, commission, vacancy, acting-service basis |
| 07 Appropriations and public money | appropriation, obligation, award, disbursement, accounting |
| 08 Administrative rulemaking | statute, proposed rule, notice, comments, final rule, enforcement basis |
| 09 Evidence and record integrity | source capture, authentication, conflict, retention, disclosure limits |
| 10 Admissibility and consequence gates | conditions required before a proposed action can have effect |
| 11 Execution receipts and provenance | request, decision, execution, denial, effect, and audit receipts |
| 12 Judicial effect and review | case, issue, disposition, scope, stay, appeal, implementation boundary |
| 13 Election and certification integrity | registration, ballot, tabulation, canvass, certification, contest |
| 14 Emergency authority | trigger, declaration, scope, duration, renewal, termination, review |
| 15 Public procurement and external execution | contract, vendor, delegated function, oversight, performance, exit |
| 16 Automated and hybrid systems | human principal, system capability, authorization, logging, override |
| 17 Remedy, challenge, and correction | complaint, standing, review, pause, reversal, correction, remedy |
| 18 Public observability | citizen-readable chain views, disclosures, redaction rationale, access |
| 19 Schemas and vocabularies | common identifiers, states, contracts, controlled terms |
| 20 Conformance and proof | test cases, proof-of-block, replay, adversarial validation |
| 21 Registers and status | authoritative repository indexes and current record status |
| 22 Freeze and releases | manifests, hashes, release decisions, supersession lineage |

The numbered order is a dependency order, not a hierarchy of institutions.
