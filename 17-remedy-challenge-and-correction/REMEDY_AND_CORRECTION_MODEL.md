# Remedy, Challenge, and Correction Model

Every consequential effect must preserve a lawful route for challenge, pause, correction, reversal, compensation where applicable, and durable closure. Remedy does not arise from a repository label; it is recorded only through the lawful process that supplies it.

`effect receipt -> challenge or review entry -> competent decision-maker -> interim protection where applicable -> correction/reversal/remedy -> successor receipt -> closure with provenance`

A correction does not erase the original action. It links a successor record to the original effect so a citizen can reconstruct what occurred, what changed, why it changed, and which lawful route produced the change.

An effect with no identified review or remedy route cannot represent itself as fully accountable.
