# Register Index

The first admitted registers are:

- Constitutional source register
- Office and role register
- Delegation and revocation register
- Jurisdiction register
- Legislative-to-statute register
- Appropriation-to-disbursement register
- Evidence conflict register
- Consequence-gate register
- Execution-receipt register
- Challenge/remedy register

Each register entry must expose its status, source references, last verified time, and supersession or invalidation lineage.
