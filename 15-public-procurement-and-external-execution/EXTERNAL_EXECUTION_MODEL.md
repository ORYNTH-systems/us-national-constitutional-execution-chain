# Public Procurement and External Execution Model

Government may obtain capability from external parties, but capability does not transfer public authority. A contractor, platform, consultant, grantee, data provider, or automated service must be linked to a bounded public purpose, accountable principal, governing instrument, scope, payment chain, information boundary, performance receipt, and remedy route.

`public authority -> procurement or instrument -> accountable public principal -> bounded external role -> monitored execution -> receipt -> review/remedy`

No external actor may be treated as self-authorized merely because it possesses data, technical capacity, funds, access, or a commercial relationship with government.
