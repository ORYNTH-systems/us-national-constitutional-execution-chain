# Delegation and Revocation Runtime Model

Delegation is a bounded transfer of already-held authority, evaluated at effect time.

`source authority -> competent delegator -> bounded delegate -> scope and conditions -> time validity -> no revocation/supersession -> effect-time check`

Delegation cannot cure an absent office, supply missing jurisdiction, enlarge the delegator's scope, survive revocation, or transform technical capability into authority. An unresolved revocation claim or expiration blocks further consequential action.
