# Federalism Interface Model

The system records boundaries before effects. Federal, state, territorial, tribal, local, judicial, executive, legislative, and private execution roles remain distinguishable even when an action involves more than one.

Each asserted action identifies actor, subject, geographic reach, institutional plane, time boundary, authority basis, and any claimed conflict rule. An overlap is not a blank check: the record shows what each participant may do, what it may not do, and the route for resolving conflict.
