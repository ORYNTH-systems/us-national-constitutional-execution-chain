## Design rules

1. Source is not interpretation.
2. Institutional presence is not proof of jurisdiction.
3. Capability, possession, wealth, consensus, or successful action do not create authority.
4. Delegated authority can never exceed the delegator's lawful scope.
5. Evidence does not adjudicate itself; unresolved material conflict blocks irreversible consequence.
6. Execution is not effect; every consequential effect requires a receipt and a review path.
7. Finality preserves provenance and remains challengeable through defined lawful routes.
