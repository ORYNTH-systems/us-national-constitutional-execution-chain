# Public Execution Conformance

| Case | Condition | Required result |
| --- | --- | --- |
| PE-001 | Program objective without appropriation link | `BLOCK` |
| PE-002 | Obligation exceeds or lacks upstream funds record | `BLOCK` |
| PE-003 | Payment lacks linked outcome receipt | `BLOCK` |
| PE-004 | Agency action lacks statutory/delegation path | `BLOCK` |
| PE-005 | Final effect relies on guidance where required procedure is unresolved | `BLOCK` |
| PE-006 | Contractor action lacks accountable public principal | `BLOCK` |
| PE-007 | External actor scope exceeds governing instrument | `BLOCK` |
| PE-008 | Money, action, external role, receipt, and remedy path are linked | `ELIGIBLE_FOR_NEXT_GATE` |

The final result means only that the public-execution chain may proceed to evidence and consequence assessment. It is not a legal conclusion or permission.
