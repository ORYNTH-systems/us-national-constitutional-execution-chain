# Full Chain Proof Suite

The foundation proof suite exercises the boundary failures that the national chain is designed to expose. Its expected results are structural assertions, not determinations about any real governmental action.

| Proof family | Required outcome |
| --- | --- |
| Unknown or unlinked source | fail closed |
| Authority carried by an invalid or stale office | block |
| Delegation beyond its source or scope | block |
| Jurisdiction conflict or missing boundary | route or block |
| Procedure absent where applicable | incomplete or block |
| Unresolved predicate or conflicted evidence | block |
| Effect without a valid gate or receipt | block or incomplete |
| Stale automated authorization | block and create stop event |
| Certification without lifecycle provenance | block |
| Emergency continuation outside time or scope | block |
| Remedy or public trace omitted | incomplete |

Passing a vector proves only that the model rejects the specified missing or invalid link. It does not confer authority or validate a real-world decision.
