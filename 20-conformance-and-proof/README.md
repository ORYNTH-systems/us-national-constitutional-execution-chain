# 20-conformance-and-proof

Holds test cases, adversarial proofs, replay checks, and proof-of-block results; no assumed conformance.

## Required record links

Every admitted record must link to its source, actor or office, jurisdiction, time validity, evidence, status, and review path where applicable.

## Admission boundary

A missing or disputed material link remains explicit. It cannot be silently converted into a valid consequence.
