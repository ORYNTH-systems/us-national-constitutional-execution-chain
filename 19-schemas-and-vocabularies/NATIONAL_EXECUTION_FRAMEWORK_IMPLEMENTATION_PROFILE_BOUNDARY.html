Implementation profile boundary

This release provides a reference framework, not a universal deployable software product. Any implementation profile must identify: the bounded workflow; legal basis; source families; data elements; access rules; human decision responsibilities; effect boundary; hold and escalation behavior; receipt format; audit method; and challenge/remedy route.

Implementation profiles must be versioned separately from v1.0.0, tested against their own institutional rules, and must not claim that the reference framework has made a factual, legal, or governmental determination.
