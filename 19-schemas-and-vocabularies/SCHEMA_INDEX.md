# Schema Index

All records use immutable identifiers and link to their supporting source, actor/office, jurisdiction, authority/delegation, evidence, time window, state, and receipt.

Initial shared contracts:

- `AUTHORITY_CHAIN_RECORD.schema.json`
- `CONSEQUENCE_GATE.schema.json`
- `EXECUTION_RECEIPT.schema.json`

Additional schemas are admitted only when their terminology does not collapse source into interpretation, evidence into authority, or execution into effect.
