v1.1.0 public-interface map

Version 1.1.0 makes the released reference framework legible to public, institutional, legal, technical, and audit readers. It adds navigation, adoption orientation, governance materials, and a public release boundary. It does not revise the frozen v1.0.0 constitutional reference baseline.

  1. Understand: use PUBLIC_START_HERE.md and the executive overview.
  2. Navigate: use the reader guide and namespace map.
  3. Apply responsibly: use adoption paths, applicability matrix, pilot-readiness material, and the implementation-profile boundary.
  4. Participate and verify: use governance, contribution, security, citation, changelog, and conformance records.

The framework baseline remains v1.0.0. v1.1.0 is a public-interface and adoption-readiness release only.
