Namespace map and preservation boundary

This repository contains historically established directories whose names may appear adjacent or overlapping. They are preserved because the v1.0.0 framework release is reconstructible from its recorded inventory and digests. Apparent naming overlap must not be treated as a license to rename, merge, delete, or infer equivalence among records.

Examples requiring careful reading

  • 12-judiciary contains the federal-judiciary reference slice developed for the v1.0.0 baseline.
  • 12-judicial-effect-and-review is a separate established domain in the wider directory architecture.
  • 22-freeze-and-releases contains the v1.0.0 release and reconstruction boundary records.
  • 22-freeze-and-release is a separately preserved established directory name.

Rule for future work

Future public-interface and adoption work may add maps and cross-references, but must not alter frozen v1.0.0 artifact paths, contents, release inputs, or claims. Any future consolidation requires a separately versioned migration plan, an inventory map, a compatibility statement, and a new integrity proof.
