# Administrative Rulemaking Model

An agency action is not self-authorizing. A rulemaking chain identifies the operative statute, agency and office, delegation, proposed action, required procedure, public record, material evidence, final action, effective date, exceptions, enforcement basis, and review path.

`statutory basis -> competent agency/office -> bounded delegation -> proposed rule -> required procedure -> evidence/rationale -> final rule -> effective time -> implementation -> review/remedy`

Guidance, announcements, memoranda, enforcement posture, technical standards, and final rules must remain distinct records. A label cannot replace the procedure and authority actually required for the asserted effect.
