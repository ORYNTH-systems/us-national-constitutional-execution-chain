National Constitutional Execution Reference Framework — v1.1.0

Designation: public-interface and institutional-adoption-readiness release.

Purpose: make the v1.0.0 reference framework intelligible, navigable, citable, governable, and responsibly approachable by external readers without representing it as a live governmental system.

Preserved boundary: this release does not appoint a reviewer, resolve an obligation, admit a governmental fact, transfer authority, produce a legal effect, or produce a governmental effect. The v1.0.0 frozen baseline remains intact and separately identifiable.

Release rule: readers may use this repository to understand, assess, and propose bounded implementation profiles. Any live institutional use requires independent lawful authority and its own implementation, security, records, privacy, accessibility, review, remedy, and effect controls.
