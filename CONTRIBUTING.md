# Contributing

Thank you for helping improve the clarity, traceability, and practical use of this reference framework.

## Before proposing a change

1. Identify the exact record, claim, path, or interface involved.
2. State whether the change is editorial, additive, corrective, or a proposed framework revision.
3. Preserve the distinction between source, evidence, interpretation, authority, decision, and effect.
4. Do not add a current governmental fact, reviewer, decision, authority transfer, or legal effect without the separately required institutional process.
5. Do not modify a frozen release artifact in place.

## Useful contribution types

- Reader-guide and accessibility improvements.
- Source provenance corrections with reproducible evidence.
- Clearly bounded vocabulary or schema proposals.
- Test cases that demonstrate a bypass must fail closed.
- Implementation-profile questions that state their institutional assumptions.

## Review expectation

Submitting material does not make it accepted. A proposal remains a proposal until a recorded, versioned repository decision accepts it.
