# Public release visual assets

`ncec-public-interface-hero-5x2.png` is the 5:2 public entry image for the National Constitutional Execution Reference Framework. It is a navigational presentation asset: it summarizes the framework's stated scope and version relationship, but is not evidence of a governmental fact, authority determination, or operational deployment.

The authoritative scope, integrity, release, and non-operational boundaries remain in the linked repository records.
