# Execution Receipt and Provenance Model

Execution and effect are separate events. An execution receipt records what was attempted or performed; an effect receipt records the observed consequence, affected object or person, time, system or actor, upstream gate, and available correction path.

Receipts are append-only provenance objects. A later correction, reversal, dispute, or remedy creates a linked successor record; it does not erase the earlier receipt.

An action cannot claim completed consequential effect where the required receipt, provenance link, time, scope, or review/remedy reference is absent.
