# Evidence and Record Integrity Model

Evidence supports an assessment; it does not adjudicate itself. This layer preserves what was observed, how it was obtained, its source and custody path, the claim or predicate it bears on, known limitations, conflicts, and applicable retention/review constraints.

`observation -> provenance -> integrity check -> relevance to predicate -> conflict/limitation assessment -> admissibility decision`

An official statement, dashboard, model output, contractor report, screenshot, public claim, or data extract may be useful evidence. None becomes authority or final consequence merely because it is recorded.

Material uncertainty, conflict, alteration, absent provenance, stale state, or incomplete collection remains visible. It cannot be silently normalized away when a consequential effect depends on it.
